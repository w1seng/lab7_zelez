# Бот-вікторина «Мандрівки Україною»

Telegram-бот на Ruby (гем `telegram-bot-ruby`). Задає запитання з варіантами
відповідей, перевіряє відповідь і підраховує результат. Запитання зберігаються
в `data/questions.json`.

## Встановлення

```
git clone <адреса репозиторію>
cd quiz-bot
bundle install
```

Потрібен Ruby 3.0+ та токен бота від @BotFather (`/newbot`).

## Запуск

```
# Linux / macOS
export TELEGRAM_BOT_TOKEN="123456:ABC..."
bundle exec ruby bot.rb

# Windows PowerShell
$env:TELEGRAM_BOT_TOKEN = "123456:ABC..."
bundle exec ruby bot.rb
```

Токен не зберігається в коді й не потрапляє до Git.

## Команди бота

| Команда | Дія |
|---|---|
| `/start` | привітання та короткий опис |
| `/quiz` | почати вікторину (запитання йдуть у випадковому порядку) |
| `/stop` | завершити вікторину й показати результат |
| `/help` | список команд |

Під час вікторини варіанти відповідей показано кнопками клавіатури. Текст,
якого немає серед варіантів, бот не зараховує як відповідь.

## Формат запитань

```json
{ "text": "Питання?", "options": ["A", "B", "C", "D"], "answer": 1 }
```

`answer` — індекс правильного варіанта (з нуля). Файл перевіряється під час
запуску: порожній текст, менше двох варіантів або індекс поза межами
зупиняють бота з поясненням помилки.

## Структура

```
bot.rb              підключення до Telegram, цикл bot.listen, обробка помилок
lib/quiz.rb         логіка: Loader, Session, Handler (без залежності від Telegram)
data/questions.json запитання
test/quiz_test.rb   тести (minitest)
```

## Тести

```
ruby test/quiz_test.rb
```

Тести використовують заглушку замість Telegram API, тому токен і мережа не
потрібні.

## Посилання на бота

Бот не розгорнуто на постійному хостингу: працює, поки запущено `bot.rb`.
